= auth-service API
:doctype: book
:icons: font
:toc: left
:toclevels: 2

회원, GitHub·Google 로그인, JWT 발급·갱신, JWKS. 이 문서는 테스트(Spring REST Docs)가 만든 실제 요청·응답으로 만든다.

* 외부 경로는 web → api-gateway를 거친다. `/auth/**`는 인증이 없고, `/api/v1/**`는 게이트웨이가 JWT를 검증해 `X-User-Id`를 붙인다.
* 오류는 모두 `{error: {code, message, traceId}}` 형식이다 (docs `api-conventions.md`).

== 로그인

=== 로그인 시작
`GET /auth/login/{provider}` (`github`, `google`). 공급자 로그인 화면으로 302. 설정되지 않은 공급자는 404.
공급자는 `{PUBLIC_BASE_URL}/auth/callback/{provider}`로 돌아오고, 로그인이 끝나면 web의 `/auth/complete?code=`로 일회용 코드를 넘긴다.
